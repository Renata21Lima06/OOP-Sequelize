# 📦 OOP-Sequelize

Repositório criado para os estudos da disciplina **Desenvolvimento Web II**, com foco em **Programação Orientada a Objetos (OOP)** e uso do ORM **Sequelize**.

## 📚 Conteúdos

- Conceitos básicos de OOP com Node.js
- Integração com banco de dados usando Sequelize
- Criação de Models, Migrations e Seeds
- Operações CRUD

## 🧰 Tecnologias

- Node.js
- Sequelize
- Express.js
- Banco de Dados (MySQL)
